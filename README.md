# 📊 IT Operations Efficiency Analysis

**Role:** IT Business Analyst (Portfolio Project)  
**Tools:** Microsoft Excel (Pivot Tables, Data Validation), PowerPoint  
**Domain:** IT Service Management (ITSM)

## 📌 Executive Summary
Analyzed 250+ historical IT support tickets to identify operational bottlenecks. The analysis revealed that **30% of help desk volume** consisted of low-complexity tasks suitable for automation, while hardware resolution times were negatively impacting SLA compliance by **200%**.

## 🔍 Key Insights
1.  **High Volume, Low Complexity:** "Access/Login" issues account for **30% of all tickets** but have a resolution time of <1 day.
2.  **The Hardware Bottleneck:** "Hardware Failures" take an average of **9.5 days** to resolve, creating significant downtime for employees.
3.  **Process Validation:** The current triage system is effective; "Critical" tickets are resolved faster (4.2 days) than "Low" priority ones (4.6 days).

## 💡 Strategic Recommendations
* **Automate:** Implement a self-service password reset tool to reduce ticket volume by ~30%.
* **Inventory Management:** Procure a buffer stock of critical hardware components (RAM, SSDs) to reduce hardware resolution time.
* **SLA Monitoring:** Continue the current prioritization logic as it correctly aligns with business urgency.
